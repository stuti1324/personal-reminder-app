Personal Reminder Application

A simple desktop reminder application developed using Python.

Features:
Add reminders
Store reminders using SQLite database
Display saved reminders
Edit existing reminders
Delete reminders
Validate reminder date
Clear input fields after adding or editing

Technologies Used:
Python
Tkinter – for the graphical user interface
SQLite3 – for storing reminders
Datetime – for date validation and handling

How to Run:
Make sure Python is installed.
Download or clone this repository.
Open the project folder in VS Code.

Run:
python reminder_app.py

Date Format:
Enter the date in:
YYYY-MM-DD

Example:
2026-08-20

Project Purpose:
This project was created as a beginner-friendly Python desktop application to practice GUI development, database management, functions, input validation, and CRUD operations.
